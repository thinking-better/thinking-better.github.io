# Thinking Better

Personal website and professional profile of Athul, a Lead AI/ML Engineer.

🌐 **Website:** https://thinking-better.github.io

---

## About

This repository contains the source for my personal GitHub Pages website.

The site serves as a concise professional profile covering my experience,
technical interests, selected projects and writing.

My work sits at the intersection of:

- Machine Learning
- Statistical & Bayesian Modelling
- Forecasting
- Commercial Analytics
- Generative AI
- Data & ML Systems

I am particularly interested in understanding problems deeply and turning
complex analytical problems into scalable, interpretable and reusable systems.

---

## Site Structure

The public site is intentionally minimal:

| Section | Purpose |
|---|---|
| **About** | Professional background, engineering philosophy and areas of interest |
| **Projects** | Selected technical projects and case studies |
| **Writing** | Technical writing and essays — coming soon |

---

## Technology

The website is built using:

- HTML
- CSS
- Markdown
- Jekyll
- GitHub Pages

The site uses a lightweight static architecture with a small number of
shared layouts and minimal dependencies.

## Development

The site is deployed through GitHub Pages from the `main` branch.

Changes pushed to `main` are automatically built and deployed by GitHub Pages.

For local development, Jekyll can be used to preview the site before publishing.

---

## Philosophy

The site is part of a broader effort to document how I think, learn and build.

The public website is deliberately kept concise.

Detailed notes, experiments and ongoing learning are maintained separately,
while this repository focuses on the professional layer:

> **Understand deeply. Build deliberately. Make the process repeatable.**
